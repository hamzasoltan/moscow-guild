# نقابة موسكو — Moscow Guild

موقع تعريفي عربي RTL لنقابة موسكو، بتصميم مستوحى من هوية الصقيع: خلفيات كحلية، أزرق جليدي، بنفسجي فاتح، بطاقات متجاوبة وشعار ثلجي SVG مضمّن داخل الصفحة.

## تشغيل محلي
افتح `index.html` مباشرة في المتصفح. الموقع ثابت ولا يحتاج إلى Node.js أو عملية build.

## النشر
الموقع مجهز لـ GitHub Pages من فرع `main` وجذر المستودع.

## أقسام الموقع
- الرئيسية والهوية البصرية
- القيادة العليا
- الوزارات
- فريق الإشراف
- رابط إعلانات النقابة على واتساب

خط Alexandria يتم تحميله من Google Fonts عند توفر الإنترنت، مع بدائل نظامية.
